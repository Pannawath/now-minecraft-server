# เอกสารนี้เก็บเป็นความลับเพื่อไม่ให้ผู้เล่นคนอื่นรู้
# คำสั่งทั้งหมดทำงานผ่านเซิร์ฟเวอร์โดยตรง ไม่ทำลายบล็อก และไม่ทำร้ายเลือดผู้เล่น

[1] เสกเงามืดปริศนา (The Watcher) ไปยืนจ้องมองเพื่อน:
/execute as <ชื่อเพื่อน> at @s run function horror:watcher
- คำอธิบาย: ร่างเงามืดหัวดำจะปรากฏตัวจ้องมองเพื่อนจากระยะ ~28 บล็อก และเมื่อเพื่อนเดินเข้ามาใกล้ (< 14 บล็อก) หรือหันมามอง จะสลายตัวเป็นควันพร้อมเสียงหัวใจเต้น

[2] แอบยัดเสียงกระซิบ / เสียงถ้ำ / เสียงฝีเท้า เข้าหูเพื่อนคนเดียว:
/execute as <ชื่อเพื่อน> at @s run function horror:whisper
- คำอธิบาย: ส่งเสียงลมหายใจและเสียงถ้ำก้องกังวานเข้าหูผู้เล่นเป้าหมายโดยตรง คนรอบข้างจะไม่ได้ยิน

[3] สั่งให้หน้าจอเพื่อนดับวูบ (The Flicker):
/execute as <ชื่อเพื่อน> at @s run function horror:flicker
- คำอธิบาย: ทำให้หน้าจอของเพื่อนมืดสนิทชั่วขณะ (สถานะ Darkness 1-2 วินาที) พร้อมเสียงลึกลับ

[4] บังคับสุ่ม 1 ใน 3 เหตุการณ์หลอนใส่เพื่อนทันที:
/execute as <ชื่อเพื่อน> at @s run function horror:trigger_random
